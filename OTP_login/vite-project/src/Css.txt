2.Transisition:

```css
transition: [property] [duration] [timing-function] [delay];

```

- **`property`**: The CSS property to which the transition is applied. Using **`all`** applies the transition to all properties.
- **`duration`**: The time it takes for the transition to complete. For example, **`0.2s`** means 200 milliseconds.
- **`timing-function`**: Defines the speed curve of the transition. Common values include **`ease`**, **`linear`**, **`ease-in`**, **`ease-out`**, and custom cubic-bezier functions.
- **`delay`**: The time to wait before starting the transition. For example, **`0.1s`** means a 100-millisecond delay.


### **Common Easing Functions**

- **`ease`**: Default value. Starts slow, speeds up, then slows down,Equivalent to **`cubic-bezier(0.25, 0.1, 0.25, 1)`**.
- **`linear`**: Constant speed,Equivalent to **`cubic-bezier(0, 0, 1, 1)`**
- **`ease-in`**: Starts slow, then speeds up,Equivalent to **`cubic-bezier(0.42, 0, 1, 1)`**.
- **`ease-out`**: Starts fast, then slows down,Equivalent to **`cubic-bezier(0, 0, 0.58, 1)`**
- **`ease-in-out`**: Starts slow, speeds up, then slows down,Equivalent to **`cubic-bezier(0.42, 0, 0.58, 1)`**.

3.Translate:

```html
<style>
    .parent {
      position: relative;
      display: flex;
      align-items: center;
      justify-content: center;
      padding: 0.5rem;
      border: 1px solid #ccc;
      border-radius: 0.5rem;
    }
    .icon {
      position: absolute;
      top: 50%;
      left: 50%;
      transform: translate(-50%, -50%);
      width: 1.2rem;
      height: 1.2rem;
      transition: all 0.3s ease-in;
    }
    .sun {
      transform: rotate(0deg) scale(1);
    }
    .moon {
      transform: rotate(90deg) scale(0);
    }
    .dark .sun {
      transform: rotate(-90deg) scale(0);
    }
    .dark .moon {
      transform: rotate(0deg) scale(1);
    }
  </style>
</head>
<body>
  <div class="parent">
    <div class="icon sun"></div>
    <div class="icon moon"></div>
  </div>
</body>
</html>

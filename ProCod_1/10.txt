box sizing in css
Great question! Let's break it down step by step so it's super clear.

---

## 🧱 Normally (default): `box-sizing: content-box`

### What happens:
- The **`width` and `height`** apply **only to the content**.
- **Padding** and **border** are **added outside** the content size.
- So, the final size of the box is **bigger** than what you set with `width` and `height`.

### Example:
```css
div {
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

| Property | Value |
|----------|-------|
| Content width | 200px |
| Padding | 20px on each side (left + right = 40px) |
| Border | 5px on each side (left + right = 10px) |

👉 **Total box width = 200 + 40 + 10 = 250px**

---

## ✅ With `box-sizing: border-box`

### What happens:
- The **`width` and `height`** now include **content + padding + border**.
- The box size stays exactly what you set in `width` and `height`.
- CSS just squeezes the content to make room for padding and border.

### Same example, but with `box-sizing`:
```css
div {
  box-sizing: border-box;
  width: 200px;
  padding: 20px;
  border: 5px solid black;
}
```

| Property | Value |
|----------|-------|
| Total width | 200px (unchanged) |
| Border | 5px each side |
| Padding | 20px each side |
| 👉 Content width | 200 - 40 - 10 = **150px** |

So now:
👉 **Total box width = exactly 200px** — consistent and easier to manage layouts.

---

## ✅ TL;DR:

| Feature | `content-box` (default) | `border-box` |
|--------|-------------------------|--------------|
| `width` includes | Content only | Content + Padding + Border |
| Easier layout? | ❌ Not really | ✅ Yes, very |
